# cc-turtle-lab

Sandbox for ComputerCraft turtle tests.

## break_up.lua

A turtle that breaks the block above itself. Put a pickaxe into its
inventory: it equips the pickaxe and digs up whenever there is a block above.

Install on a turtle (run on the turtle):

```
delete startup
wget https://raw.githubusercontent.com/Kapebara07/cc-turtle-lab/main/break_up.lua startup
reboot
```
